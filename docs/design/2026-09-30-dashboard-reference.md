# 웹 서비스 디자인 기준 v1

사용자 제공: 2026-09-30. 기준 사이트:
[소셜 애널리틱스 대시보드 — 라이트 모드 KPI·차트 구성](https://ref.theseeker.io/r/2437).
원작자 표기: Rakibul / @rakibulism. 페이지와 확대 원본 이미지를 브라우저에서 확인했다.

## 관찰한 구성

- 밝은 화면, 고정 왼쪽 사이드바, 얇은 구분선이 있는 상단 헤더.
- 사이드바는 로고, 메뉴 그룹, 선택 상태, 하단 설정·사용자 영역으로 구성된다.
- 헤더는 현재 위치, 길쭉한 검색 영역, 보조 동작을 담는다.
- 콘텐츠 상단에는 탭·필터와 날짜가 있고, 아래에 지표 카드가 같은 높이로 놓인다.
- 큰 콘텐츠 카드와 오른쪽 보조 카드의 비율은 약 2:1이다.
- 하단에는 미디어를 포함한 카드들이 이어진다.
- 흰 카드, 작은 그림자, 얇은 테두리, 큰 모서리 반경을 사용한다.
- 숫자는 굵게, 설명·라벨은 작은 회색 글자로 표시한다. 강조색은 절제돼 있다.

페이지가 제시한 색상은 `#E6E6E6` 배경, `#FFFFFF` 카드,
`#1C1C1E` 본문, `#5AA7E0` 파랑, `#DCEAFA` 연파랑,
`#2EB872` 성공 상태다. 이미지의 회색 외곽은 소개용 프레임이므로
서비스 콘텐츠를 좁은 프레임 안에 축소하지 않는다.

## 구현 토큰과 반응형 기준

아래 수치는 참고 이미지로부터 서비스에 맞게 정한 구현 값이다.
원본의 CSS나 정확한 글꼴을 확인한 값은 아니다.

| 항목 | 구현 기준 |
| --- | --- |
| 기본 바탕 | `#F7F8FA`; 카드·헤더·사이드바 `#FFFFFF` |
| 본문 / 보조 글자 | `#1C1C1E` / `#626973` |
| 테두리 | `#E7EAEE`, 1px |
| 포인트 / 약한 포인트 | `#5AA7E0` / `#DCEAFA` |
| 성공 상태 | `#2EB872`; 글자 대비는 더 진한 별도 토큰 사용 |
| 카드 반경 | 14px; 작은 입력·버튼 8px |
| 사이드바 / 헤더 | 데스크톱 약 232px / 64px |
| 콘텐츠 여백 / 카드 간격 | 데스크톱 24px / 16px; 모바일 16px / 12px |
| 타이포 | 시스템 산세리프, 한국어 폴백; 본문 14px, 설명 12px, 제목 24px |
| 선택 상태 | 짙은 중립색 또는 옅은 회색 바탕; 색상과 텍스트/아이콘을 함께 사용 |
| 작은 화면 | 접을 수 있는 메뉴, 세로 카드 배치, 수평 넘침 없는 폼·매장 선택 |

## APK 웹 서비스에 적용

레이아웃과 시각적 위계는 이 기준을 따르고, 데이터와 동작은 APK 구현
계획의 기능 계약을 따른다. 소셜 플랫폼·캠페인 내용은 서비스 기능으로
추가하지 않는다. 확인된 실제 데이터만 지표로 표시하고, 카메라·알림·미디어
데이터가 없으면 원인을 설명하는 빈 상태를 표시한다.

T03 로그인 화면은 같은 색·간격·카드 스타일을 사용한다. 매장 선택 화면은
사이드바와 헤더, 권한 있는 매장 카드, 선택 상태, 로그아웃 동작을 제공한다.
후속 W03의 기기·실시간 영상·재생·알림·앨범·설정 화면이 같은 토큰을 공유한다.
사용자에게 개발 작업명이나 구현 진행 설명을 제품 화면으로 보여주지 않는다.

## 확인할 화면

로그인, 인증 오류, 매장 없음, 한 매장, 여러 매장, 직원 제한, 만료된 세션,
허용되지 않은 매장 URL, 모바일 메뉴와 키보드 이동을 확인한다.
중립색 본문·명시적 포커스·상태 텍스트로 대비와 접근성을 확보한다.
스크린샷 검토와 실제 HTTPS 브라우저 테스트 결과를 구현 기록에 연결한다.

G-P8의 사용자 참고 사이트 입력은 확보됐다. 후속 화면의 시각적 승인과
반응형 검증은 아직 진행 중이며, 다른 APK 기능의 실증 게이트와 별개다.
